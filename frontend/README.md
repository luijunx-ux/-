# Frontend

天人律 Flutter 移动端，包含 Android 与 iOS 平台工程。

## 本地运行

```powershell
flutter pub get
flutter run --dart-define=API_BASE_URL=http://10.0.2.2:8000
```

Android 模拟器通过 `10.0.2.2` 访问宿主机；真机调试时请将地址替换为开发机可访问的
局域网地址。生产构建必须显式传入 HTTPS API 地址。

## 当前功能

- 邮箱注册与登录，启动时自动校验已保存会话
- Access Token 失效后使用轮换式 Refresh Token 恢复会话，退出时服务端同步撤销
- 应用运行期间受保护请求遇到 401 会合并并发刷新、轮换令牌并自动重试一次
- 登录页可请求密码重置邮件，账户页可请求邮箱验证邮件
- Web 邮件链接可直接完成邮箱验证或进入新密码设置页面
- 访问令牌通过 Android Keystore / iOS Keychain 对应的系统安全存储保存
- 账户退出，以及带二次确认的账户与档案永久注销
- 自动保存生成的生命档案，并支持档案列表、详情、下拉刷新和单条删除
- 今日节律首页自动展示默认档案，可自定义名称、编辑出生资料并切换默认档案
- 同一档案同一天复用 AI 建议缓存，支持历史记录、有效性反馈和连续查看天数
- 出生日期、时间、地点、经纬度和 IANA 时区录入
- 点击搜索地点并自动填写标准名称、经纬度和 IANA 时区
- 后端生命档案生成接口对接
- 星座和五运六气结果展示
- 按日期查看每日生命建议，支持下拉刷新和失败重试
- 请求失败、输入校验、节气边界与健康免责声明提示

密码至少需要 12 个字符。客户端不会保存明文密码；已登录请求会使用 Bearer Token，令牌
失效后应用会清理本地会话并要求重新登录。

地点数据来自 OpenStreetMap Nominatim 公共服务。客户端不会执行逐字自动补全；所有搜索由
用户明确触发，后端负责限速与缓存。正式商业发布前应切换至自托管或具备 SLA 的地理服务。
