## 工程与部署

- [ ] GitHub Actions 后端 lint、类型检查、测试、Flutter analyze/test 和密钥扫描全部通过。
- [ ] 发布提交已打版本标签，镜像使用不可变标签并记录摘要。
- [ ] Android Release 使用专用上传/发布密钥签名；调试密钥、`key.properties` 和 keystore 未进入 Git。
- [ ] 生产变量无模板密钥，PostgreSQL/Redis 不暴露公网端口。

## 安全与隐私

- [ ] 仓库、镜像、日志和构建产物中无真实密钥、令牌或用户数据。
- [ ] 注册、登录、刷新、退出、限流、账户隔离和删除级联测试通过。
- [ ] TLS、SMTP、密钥轮换、最小权限和日志保留策略已配置。
- [ ] 隐私同意、数据用途、删除入口和免责声明由人工审核。
- [ ] 完成依赖漏洞检查；高危漏洞无未批准例外。

## 产品与内容

- [ ] 本版本涉及的 UI 已获得用户明确“视觉审核通过”。
- [ ] Forest Life、Obsidian Life 及支持的字体缩放场景通过双主题检查。
- [ ] 五运六气和星辰节律保持同等级入口；LLM 未参与确定性计算。
- [ ] 建议内容温和、可执行、非宿命，不包含诊断、治疗、用药或绝对预测。
- [ ] 生命参考分满足 V0.1 数据质量门禁；不满足时显示状态标签或“数据不足”。
- [ ] AI 降级、数据缺失/过期、模型超时和高风险表达拦截已验证。
