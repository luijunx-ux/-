# 天人律 0.3.0-alpha.1 发布说明

## 定位

这是用于受控测试的首个 Alpha 就绪候选版本，不是公开医疗产品，也不提供诊断、治疗、用药或
确定性事件预测。正式放行仍需完成 GitHub 门禁和四类负责人签字。

## 主要能力

- Forest Life、Obsidian Life 与生活照片方向的首页体验基础。
- 五运六气与星辰节律双核心入口，以及通俗生活方式解释。
- 出生资料、生命档案、太阳星座、每日建议和反馈记录基础链路。
- 账户注册、登录、刷新会话、验证/重置邮件、限流与用户数据隔离。
- 生命参考分 V0.1 展示门禁和重点状态记录体验。
- 请求追踪、结构化脱敏日志、存活/就绪检查及生产配置快速失败。

## Alpha 工程门禁

- 后端 lint、类型检查、单元/集成测试及 Flutter analyze/test。
- Git 历史密钥扫描、Python 依赖审计、CycloneDX SBOM 和容器漏洞扫描。
- 非 root 容器运行、全量数据库迁移、PostgreSQL/Redis 就绪检查。
- 合成数据备份、恢复、迁移重放和恢复后健康检查。

## 已知限制

- 五运六气知识规则仍须专家和黄金测试集审核，当前内容不能作为权威医学结论。
- 实时天气/AQI、可穿戴数据、月亮/上升星座和完整多 Agent 编排不属于本 Alpha 范围。
- 正式 SMTP、模型供应商、监控告警、加密异地备份和原生深链接需在部署环境配置。
- 数值生命参考分仅在 V0.1 数据质量门禁满足时显示，否则显示状态或“数据不足”。

## 升级与回滚

部署前必须备份 PostgreSQL、记录镜像摘要和迁移版本。异常时优先回退上一稳定镜像；仅在恢复
负责人批准且已验证必要性后恢复数据库。禁止通过关闭鉴权、安全检查或数据隔离来完成回滚。
