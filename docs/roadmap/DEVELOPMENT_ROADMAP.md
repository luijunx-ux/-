# 天人律开发阶段基线

原始规划采用 Sprint 0–7。当前仓库已有跨阶段实现，因此本路线图用于判断能力归属，不用于删除已完成代码。

| 阶段 | 原规划重点 | 当前处理原则 |
|---|---|---|
| Sprint 0 | 工程初始化 | 已完成 |
| Sprint 1 | 生命档案与隐私 | 已有实现，持续验证 |
| Sprint 2 | 历法/四柱基础引擎 | 已部分跨阶段实现，须补权威校验 |
| Sprint 3 | 五运六气与专家验证门 | 已有实现，不能视为专家审核完成 |
| Sprint 4 | 太阳星座与 Fusion 基础 | 太阳星座已有实现，融合模型待核验 |
| Sprint 5 | Life Agent、日报、安全与反馈 | 已有实现，持续安全评测 |
| Sprint 6 | Flutter MVP、双主题与联调 | **当前优先：UI 基线恢复** |
| Sprint 7 | 全链路、安全、部署与 Alpha | 视觉审核通过后进入 |

新阶段必须写清输入、范围、非范围、依赖、验收与回滚。质量门不因日期取消。
