# 天人律 Forest Life（森林生命）UI 设计规范

版本：V3.1
状态：首页视觉小样已通过；其他页面待视觉审核
适用：Figma、Flutter、Web Demo、Android Demo

已通过的首页视觉小样：[`previews/forest-home-approved-v1.png`](previews/forest-home-approved-v1.png)。后续实现应保持其荷叶露珠背景、深绿玻璃层次与双核心入口关系。

## 1. 主题定位

Forest Life 是天人律默认主题。核心感受为自然、柔和、呼吸、晨雾、植被与生命生长；用户应感到被自然节律温和陪伴，而不是在操作计算工具。

关键词：`森林`、`晨雾`、`叶脉`、`水滴`、`柔光`、`呼吸`、`生长`、`温暖克制`。

禁止：工业 Dashboard、高密度数据网格、医疗监护仪、命盘堆叠、霓虹赛博、纯白办公软件卡片阵列。

## 3. 设计 Token

### 3.1 色彩

| 语义 Token | 建议值 | 用途 |
|---|---:|---|
| `forest.bg.primary` | `#F5F3EA` | 页面雾白背景 |
| `forest.bg.deep` | `#DDE8DC` | 自然层次与底部渐变 |
| `forest.primary` | `#3D7A57` | 主操作、选中状态 |
| `forest.primary.deep` | `#24533A` | 强调文字、深层卡片 |
| `forest.primary.soft` | `#A9C8B1` | 柔和装饰与状态背景 |
| `forest.accent.gold` | `#C69B52` | 节气、关键提示，小面积使用 |
| `forest.text.primary` | `#183126` | 主文字 |
| `forest.text.secondary` | `#52665A` | 次级文字 |
| `forest.text.muted` | `#7B897F` | 辅助信息 |
| `forest.surface.glass` | `#FFFFFFB8` | 半透明卡片 |
| `forest.stroke.soft` | `#FFFFFF99` | 卡片高光边 |
| `forest.positive` | `#438863` | 温和正向状态 |
| `forest.warning` | `#B47B3C` | 需关注状态，不制造恐慌 |
| `forest.error` | `#A5534F` | 错误状态 |

以上为开发锚点；视觉审核调整时只能修改 token，不在页面散落替代色值。

### 3.2 渐变与材质

- 页面背景：雾白 → 浅苔绿的低对比纵向渐变。
- 生命环：森林绿、浅叶绿和少量暖金，边缘柔化。
- 卡片：半透明浅色表面、顶部细高光、低强度绿色环境阴影。
- 背景纹理：最多两层低透明叶影/雾气，不影响文字对比度。
- 禁止大面积锐利玻璃反射和高频写实森林照片。

### 3.3 字体

- 中文 UI：系统无衬线字体；标题使用中等或半粗字重。
- 品牌/节气短标题可使用克制的宋体或衬线字体，但正文不得使用。
- 页面大标题：28sp / 34 行高。
- 区块标题：20sp / 28 行高。
- 正文：16sp / 24 行高。
- 辅助文字：14sp / 20 行高；不可用于核心信息。

### 3.4 间距、圆角与阴影

- 基础间距：4；常用序列：`4, 8, 12, 16, 20, 24, 32, 40`。
- 页面水平边距：20；区块间距：24。
- 主卡圆角：28；普通卡片：20；按钮：18 或胶囊形。
- 触控目标不小于 `44 × 44`。
- 阴影：大范围、低透明、低锐度；避免灰黑硬阴影。

## 4. 核心组件

### 4.1 今日生命环

- 首页唯一中央视觉焦点。
- 以抽象叶脉、年轮或柔光环表达今日状态。
- 无批准评分算法时只显示“平衡、偏高、偏低”等状态，不显示伪精确数字。
- 环外只保留一条摘要，详细解释放在下方。

### 4.2 双核心节律卡

- `YunQiCard` 与 `ZodiacCard` 同宽、同高、同标题等级、同点击权重。
- 五运六气使用生命树、五行环或流动叶脉符号。
- 星辰节律使用月光、星点与植物轮廓，不使用娱乐占星插画。
- 每卡包含：名称、今日一句摘要、数据时间/状态、进入详情提示。

### 4.3 建议卡

- 固定四类：饮食、睡眠、运动、情绪。
- 首页展示一行可执行建议；避免玄学术语堆叠。
- 图标采用圆润自然线性风格，并配文字标签，不能只靠颜色区分。

### 4.4 AI 生命球

- 形态：水滴、种子、光球与叶脉融合的抽象生命体。
- 不能使用机器人头像、聊天气泡或拟人医生。
- 状态：待机呼吸、思考能量汇聚、回复光晕展开、离线静态雾光。

## 5. 页面规范

### 5.1 首页

顺序固定：问候/日期/地点 → 今日生命环 → 今日摘要 → 五运六气与星辰节律双卡 → 四类建议 → 数据依据与更新时间。

用户应在 5 秒内理解今日状态和第一条行动建议。天气不可用时明确显示“环境数据暂不可用”，不得伪造。

### 5.2 五运六气

以生命树或五行环承载结构化信息；先通俗摘要，再逐层展开日期、时区、节气、五运、六气、环境上下文、来源版本与免责声明。专家未校验内容必须标为草案参考。

### 5.3 星辰节律

使用林间夜色和克制星点。P0 只显示太阳星座、元素、倾向参考和生活建议；月亮与上升只显示“未来能力”。不展示桃花、财富或事件预测。

### 5.4 AI 助手

生命球占首屏主要视觉区域；对话内容以建议卡和依据卡承载，不复制普通即时通信界面。显示生成时间、数据类别和不确定性。

### 5.5 生命档案与设置

使用清晰表单，不让自然装饰降低可操作性。出生时间、地点等敏感数据只在必要位置出现；提供更正、导出和删除入口。

## 6. 动效

- 生命环/生命球待机呼吸周期约 4 秒，缩放和亮度变化保持低幅。
- 页面转场使用淡入与轻微纵向位移，建议 220–320ms。
- 卡片按压只做轻微缩放或表面变化，不使用弹跳游戏动效。
- 尊重系统“减少动态效果”；降级后信息与操作必须完整。

## 7. 状态与无障碍

- 覆盖加载、空、错误、离线、数据过期、权限拒绝状态。
- 正文不低于 16sp；系统字体放大时允许卡片增高。
- 对比度、焦点顺序、语义标签和屏幕阅读器描述必须验证。
- 所有状态配合图标/文案表达，不能只改变颜色。

## 8. Flutter 交付映射

- Figma 变量映射到 `ThemeExtension`，命名保持语义一致。
- 共用组件：`LifeStatusCard`、`YunQiCard`、`ZodiacCard`、`AdviceCard`、`LifeOrb`。
- 页面不得直接写主题色、圆角或阴影魔法数。
- Forest 与 Obsidian 共用数据模型和组件接口，允许不同的装饰层与视觉实现。

## 9. 视觉验收

- 一眼可识别为自然生命主题，而不是通用浅色 App。
- 首页双核心入口权重相等，四类建议首屏或自然滚动可见。
- 无工业 Dashboard、医疗设备或算命命盘感。
- Android、Web、窄屏和大字体无溢出。
- 必须提供真实运行截图并经用户明确回复“视觉审核通过”后，才允许 Git 提交。
