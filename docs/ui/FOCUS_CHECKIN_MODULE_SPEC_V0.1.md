# 我的重点状态与今日记录 V0.1

状态：概念视觉已于 2026-09-16 获用户确认；Flutter 首页实现已于 2026-09-19 随完整首页通过视觉审核

## 模块定位

该板块位于首页每日建议之后，用于让用户低负担地记录当下的主观状态，并回看当天的重要事件。它不替代生命参考分、设备数据或专业医疗判断。

## 信息结构

1. 我的重点状态：显示日期、记录目的与当日完成状态。
2. 系统已观察：只读呈现睡眠、活动等客观摘要，标明来源和更新时间。
3. 现在感觉怎么样：分别记录精力、压力感受、身体感受。
4. 今日备注：允许用户添加不超过 120 字的私人文字。
5. 今日记录：按时间展示系统事件、设备事件和用户主动记录。

## 冻结边界

- 客观数据与用户主观记录必须使用明确标签分开呈现。
- 本次记录不得回写或修改已经生成的今日生命参考分。
- 主观记录只有在用户授权且存在冻结规则时，才可参与下一次规则计算。
- 不根据文字或选择项自动生成诊断、治疗方案或绝对结论。
- 用户主动记录应支持编辑和删除；系统或设备记录不在此处直接修改。
- 选择“明显不适”时，只显示温和的专业帮助提示，不改变分值。

## 交互状态

- 每组状态选项单选，点击区域不小于 44px。
- 保存后顶部状态更新为“今日已记录 1 次”，按钮变为“更新今日记录”。
- 保存的记录追加到今日时间线，并提供编辑入口。
- 无备注时，时间线使用三项状态摘要作为记录内容。

## 视觉基线

- 当前小样采用 Vitality Life 第三主题的浅色生活化卡片语言。
- 颜色、圆角、阴影和文字层级与已通过的首页模块保持一致。
- 后续 Flutter 落地时仍需补齐 Forest Life 与 Obsidian Life 双主题截图，并按 UI 验收标准完成视觉审核。
