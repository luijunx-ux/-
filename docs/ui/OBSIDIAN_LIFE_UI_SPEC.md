# 天人律 Obsidian Life（黑曜生命 / 黑曜科技）UI 设计规范

版本：V3.1
状态：视觉实现基线，待用户视觉审核
适用：Figma、Flutter、Web Demo、Android Demo

## 1. 主题定位

Obsidian Life 是天人律的深色主题。核心感受为深邃、静谧、星空、能量与温暖克制的未来感；科技感用于表达生命节律和宇宙环境，不用于展示系统指标。

关键词：`黑曜石`、`深空`、`星轨`、`能量环`、`蓝紫光`、`暖琥珀`、`静谧`、`高级克制`。

禁止：交易终端、服务器监控、游戏 HUD、医疗仪表、刺眼霓虹、纯黑无层次背景、廉价赛博朋克。

### 3.2 渐变、光效与材质

- 页面背景：黑曜蓝黑 → 深靛黑的低对比径向/纵向渐变。
- 生命球：能量蓝、低饱和紫、暖琥珀三色柔和融合。
- 卡片：深色半透明表面、细微边缘光、局部环境反射。
- 星点/粒子：低密度、低亮度、慢速；不可干扰阅读或造成游戏感。
- 光晕必须柔和扩散，避免锐利外发光和大面积高饱和渐变。

### 3.3 字体

- 中文 UI：系统无衬线字体，保证深色背景可读性。
- 品牌或洞察标题可使用优雅衬线字体，但不用于表单、正文和操作。
- 页面大标题：28sp / 34 行高。
- 区块标题：20sp / 28 行高。
- 正文：16sp / 24 行高。
- 辅助文字：14sp / 20 行高；不得承载核心结论。

### 3.4 间距、圆角与阴影

- 基础间距：4；常用序列：`4, 8, 12, 16, 20, 24, 32, 40`。
- 页面水平边距：20；区块间距：24。
- 主卡圆角：24；普通卡片：18；按钮：16 或胶囊形。
- 触控目标不小于 `44 × 44`。
- 用边缘光和层级明度代替厚重黑阴影。

## 4. 核心组件

### 4.1 今日生命能量环

- 首页唯一中央视觉焦点。
- 使用柔性膜状能量环、星轨或有机光场，不使用机械仪表盘刻度。
- 无批准评分算法时只显示可解释状态，不显示伪精确分数。
- 光效服务于状态表达，不能掩盖摘要文字。

### 4.2 双核心节律卡

- `YunQiCard` 与 `ZodiacCard` 同宽、同高、同标题等级和入口权重。
- 五运六气使用有机能量星环/五行轨迹，不使用雷达图仪表。
- 星辰节律使用星轨、星座点阵和柔性光线，不做娱乐占星海报。
- 每卡包含：名称、今日一句摘要、数据时间/状态、进入详情提示。

### 4.3 建议卡

- 固定四类：饮食、睡眠、运动、情绪。
- 深色卡片内使用短句和低亮度图标；暖琥珀仅用于关键行动提示。
- 避免健康评分、红色警报和监控数据感。

### 4.4 AI 生命球

- 形态：有机能量膜、星云与柔光球融合，内部存在缓慢流动。
- 不能使用机器人、聊天头像、芯片、CPU 或医生符号。
- 状态：待机缓慢呼吸、思考能量聚合、回复蓝紫/琥珀光展开、离线静态暗光。

## 5. 页面规范

### 5.1 首页

顺序固定：问候/日期/地点 → 今日生命能量环 → 今日摘要 → 五运六气与星辰节律双卡 → 四类建议 → 数据依据与更新时间。

首屏应像安静的生命洞察空间，而不是系统控制台。环境数据缺失或过期必须明确显示，不能用视觉光效掩盖。

### 5.2 五运六气

使用有机能量环逐层表达日期、时区、节气、五运、六气和环境上下文。先给通俗摘要，再展示结构化依据、来源版本和免责声明；不可制作成监控图表。

### 5.3 星辰节律

使用星轨和低密度星点。P0 只展示太阳星座、元素、倾向参考和生活建议；月亮/上升为未来能力。不得出现桃花、财富或事件预测。

### 5.4 AI 助手

生命球是首屏主角，建议和依据以深色玻璃卡片呈现。聊天输入是辅助入口，不能让页面退化为普通聊天软件。显示数据类别、生成时间和不确定性。

### 5.5 生命档案与设置

表单层级清晰，避免 HUD 式边框和密集线条。敏感出生信息只在必要位置出现；主题、隐私、导出和删除入口可发现。

## 6. 动效

- 生命球待机呼吸周期约 4 秒；内部能量位移缓慢、连续、低幅。
- 思考态可增加能量汇聚和轨道速度，但不得快速闪烁。
- 回复态光晕在 600–900ms 内增强并回落。
- 页面转场使用淡入、景深和轻微位移，建议 220–320ms。
- 减少动态模式下以静态渐变和边缘光表达状态。

## 7. 状态与无障碍

- 覆盖加载、空、错误、离线、数据过期、权限拒绝状态。
- 深色主题必须重点验证正文、禁用态和玻璃表面的对比度。
- 正文不低于 16sp；字体放大时卡片自动增高。
- 状态不能只靠蓝、紫、琥珀颜色区别，必须配图标和文案。
- 粒子、闪光和动画不得诱发视觉不适。

## 8. Flutter 交付映射

- Figma 变量映射到 `ThemeExtension`，命名保持语义一致。
- 共用组件：`LifeStatusCard`、`YunQiCard`、`ZodiacCard`、`AdviceCard`、`LifeOrb`。
- 光效、渐变、圆角与动效时长集中管理，页面禁止魔法数。
- 与 Forest 共用数据模型和组件接口，但允许独立背景、材质、插画和生命球渲染器。

## 9. 视觉验收

- 一眼可识别为温暖克制的黑曜生命主题，而不是通用暗色 App。
- 蓝紫与暖琥珀共同构成“有生命的光”，不是赛博霓虹。
- 首页双核心入口权重相等，四类建议无需进入二级页即可看到。
- 无交易、服务器、医疗仪表或游戏 HUD 感。
- Android、Web、窄屏和大字体无溢出，深色对比度合理。
- 必须提供真实运行截图并经用户明确回复“视觉审核通过”后，才允许 Git 提交。
