# UI 高保真原型设计规范 V3.0（唯一开发基线）

定位：从视觉概念进入可开发级 UI 规范。适用于 Figma、Flutter 与 Codex 前端实现。

主题详细规范：

- [Forest Life（森林生命）](FOREST_LIFE_UI_SPEC.md)
- [Obsidian Life（黑曜生命 / 黑曜科技）](OBSIDIAN_LIFE_UI_SPEC.md)

## 体验原则

- 弱化工具感，强化陪伴感；弱化复杂数据，强化今日行动。
- 避免命盘、医疗监护仪、交易终端和服务器 Dashboard 风格。
- 内容层次：今日状态 → 双核心节律 → 今日建议 → 进一步解释。
- 页面使用语义 token，不散落颜色、圆角、阴影和间距魔法数。

## Forest Life / 森林生命（默认）

- 气质：自然、柔和、呼吸、晨雾、植被与生命生长感。
- 色彩锚点：主绿 `#3D7A57`、雾白背景 `#F5F3EA`；最终值须以视觉稿校准。
- 材质：柔和半透明卡片、自然层次、暖金小面积强调、克制玻璃感。
- 图形：叶脉、生命环、林间光、抽象植物纹理。
- 禁止：工业仪表盘、高密度网格、霓虹赛博、纯白办公卡片阵列。

## Obsidian Life / 黑曜生命（黑曜科技）

- 气质：深邃、静谧、星空、能量与温暖克制的未来感。
- 色彩锚点：背景 `#080B12`、主蓝 `#3A8DFF`，辅以低饱和紫和暖琥珀生命光。
- 材质：深色玻璃、柔光边缘、空间层次、少量粒子和轨道。
- 图形：星轨、能量环、生命光晕；科技感服务于生命节律。
- 禁止：交易终端、游戏 HUD、刺眼霓虹、纯黑无层次背景。

## AI 生命球

生命球是陪伴核心，不是普通聊天头像。待机约 4 秒低幅呼吸；思考时内部能量汇聚；回复时光晕短暂增强后回落。减少动态模式与低端设备降级为静态渐变/光晕。

## 布局与组件

- 首页中央视觉焦点只允许一个：今日生命状态/生命环。
- 五运六气、星辰节律两卡同等级、同面积级别、同入口清晰度。
- 建议卡覆盖饮食、睡眠、运动、情绪，首页可直接阅读摘要。
- 正文建议不低于 16sp；触控目标至少 44×44；支持系统字体缩放。
- 圆角、间距、字体、阴影、渐变、动效时长均由 ThemeExtension/设计 token 管理。
