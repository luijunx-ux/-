# 核心页面 UI 基线

## 首页

顶部为问候、日期、地点和天气新鲜度；中央为今日生命状态；随后是五运六气与星辰节律两个同等级主入口；下方直接展示饮食、睡眠、运动、情绪建议。

顶部板块显示内容于 2026-09-03 冻结为：日期与星期、节气及通俗阶段、个性化问候、温和陪伴文案、每日生活主图、地点、天气、温度、空气质量、图片生活主题与行动标题、节气生活提示、图片更新状态及环境数据更新时间。每日图片同一自然日保持稳定，数据缺失、过期、离线和未授权状态必须明确展示。详细字段及接口映射见 [`VITALITY_LIFE_UI_SPEC.md`](VITALITY_LIFE_UI_SPEC.md#4a-首页板块一顶部问候与每日生活主图内容冻结)。

生命参考分采用已冻结的 V0.1 规则；只有满足数据覆盖率、个人基线、数据质量和可解释性条件时才显示数值，否则使用可解释状态或“数据不足”。详细规则见 [`LIFE_REFERENCE_SCORE_V0_1.md`](../product/LIFE_REFERENCE_SCORE_V0_1.md)。用户无需进入二级页即可理解今日摘要。

## 五运六气页

展示日期/时区、干支与节气上下文、五运/六气结构化结果、环境融合、通俗解释、来源版本和免责声明。Forest 可使用生命树/五行环；Obsidian 可使用能量星环。

## 星辰节律页

MVP 只展示太阳星座、元素、倾向参考和生活建议。月亮/上升显示为未来能力，不伪造结果。不得出现桃花、财富或事件预测。

## AI 助手页

以 AI 生命球和建议卡为主，不做普通聊天软件外观。展示所用数据类别、生成时间和不确定性，支持反馈与纠错，不得伪装成医生。

## 生命档案与设置

允许查看和更正出生信息、时间精度、地点与时区；主题、通知、隐私、数据导出和删除入口清楚。敏感资料不可作为装饰性内容反复展示。
